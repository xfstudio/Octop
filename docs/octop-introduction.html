02 / 总体方向

更易用、更聪明、更安全、更省 Token。

Octop 的产品演进围绕四个明确方向展开：降低 AI 助手的使用门槛，提升复杂任务的协作与推理质量，建立可验证的安全边界，并让长程任务以更低 Token 成本持续运行。

↗
更易用

降低使用门槛，开箱即用。让用户在熟悉的 Web、CLI 与 IM 环境中，快速获得可执行的 AI 助手。

✦
更聪明

用多专家协作与上下文管理，帮助 Agent 理解更长的任务链路，完成更复杂的分工与推理。

◇
更安全

通过用户/数据隔离、权限控制和沙箱化演进，让 AI 在真实环境中工作时始终处于可控边界。

↓
更省 Token

以文件系统 offload、分层提示词与分层记忆承载长程上下文，减少无效重复推理与成本。

围绕方向打造的产品亮点

把产品理念落到可部署、可协作、可运行的能力上。

01
多用户 × 多专家架构

每位用户创建多个独立 Agent，并可从专家库选择角色；MBTI 人格与系统提示词使角色长期稳定、分工清晰，为多人轻协作与后续 AgentTeams 奠定基础。

02
存算分离与可插拔后端存储

后端存储可落在本地、Docker、COS/S3 等后端；计算与存储解耦，便于按企业基础设施部署，记忆也能随工作区迁移。

03
上下文管理与 Token 效率

文件系统 offload、分层提示词、分层记忆与全文检索，将长期信息放在需要时再取回，避免上下文窗口被无效内容占满。

04
连接器与真实环境操作

Connector（OAuth + MCP）、浏览器自动化、交互式 Shell、远程桌面与 ACP，将 AI 接入外部系统、终端、网页与 GUI 工作流。

05
主动服务与AI人格

定时任务可主动推送；MBTI 人格与自定义系统提示词让 Agent 从“被动问答”走向具有稳定服务风格的长期伙伴。

06
安全边界持续加固

当前具备 JWT 用户隔离、工具审批、Shell 命令防护与敏感信息脱敏；下一步研究 rootfs 数据隔离与 Agent 完全沙箱化。

04 / 规划

Teams / 自进化 / 客户端 / 插件机制

近期 / 安全基座

隔离从权限走向运行时

  • 研究以 rootfs 为核心的用户数据边界

中期 / 自进化与智能协作

从多个 Agent 到 AgentTeams

  • 多 Agent 编队、分工与编排
  • 把对话经验沉淀为可复用技能
  • 加强上下文管理与 Token 效率
扩展 / 产品与平台

从验证到规模化赋能

  • 浏览器录制 Octop 验证
  • PC 与移动端协同，拓宽使用场景
